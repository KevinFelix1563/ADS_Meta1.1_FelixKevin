# Agenda JavaFX - Gestión de Base de Datos

## Estructura del Proyecto

El código está estructurado separando la interfaz gráfica de la lógica de acceso a datos utilizando el patrón DAO (Data Access Object).

*   **Código Principal (`src/main/java/`):** Contiene los modelos (`Persona`, `Telefono`), el controlador de la interfaz y la clase `AgendaDAO`.
*   **Interfaz Gráfica (`src/main/resources/`):** Contiene el diseño visual en formato `.fxml`.
*   **Pruebas Unitarias (`src/test/java/`):** Contiene la prueba de unidad y de integración implementada con JUnit
